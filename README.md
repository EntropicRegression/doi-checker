# 引用與參考文獻檢查工具

上傳論文的 PDF 或 DOCX，自動整理出**內文引用**與**參考文獻列表**，比對兩邊是否對得上，並用 Crossref 線上驗證文獻資訊是否正確。結果以表格呈現，可匯出 Excel。

程式在你自己的電腦上執行，介面是本機網頁（`http://127.0.0.1:8765`）。

## 會檢查什麼

**內文引用 ↔ 參考文獻列表**

- 內文引用在列表中找不到對應的文獻
- 年份不符（例如內文寫 2018，列表是 2017）
- 作者姓氏拼字不符（例如 Krizhevski 與 Krizhevsky）
- 多作者引用中，第二位以後的作者不在該文獻的作者裡
- 作者姓氏沒有大寫，例如 `(choi, 2020)`
- 列表中的文獻沒有被內文引用
- 疑似重複的文獻、兩筆文獻的 DOI 相同
- 同作者同年份的文獻沒有用 a、b 區分

**線上驗證（Crossref，可關閉）**

- DOI 不存在
- DOI 指向另一篇文章
- 年份、第一作者與 Crossref 登記的不符
- 沒有 DOI 的文獻會用標題搜尋，找到時建議可補上的 DOI

## 支援的格式

| 項目 | 支援 |
| --- | --- |
| 檔案 | `.pdf`（需含文字層）、`.docx` |
| 作者–年份制 | `(Smith, 2020)`、`(Smith & Jones, 2020; Lee et al., 2019)`、`Smith (2020)`、`(Smith, 2020a, 2020b)` |
| 中文引用 | `王小明（2020）`、`（李大華、陳美玲，2019）` |
| 編號制 | `[1]`、`[2, 3]`、`[4-6]`、上標數字 |
| 參考文獻標題 | References、Bibliography、Works Cited、參考文獻、參考資料、引用文獻 等 |

## 安裝與啟動

需要 Python 3.9 以上。

### Windows

雙擊 `start.bat`。第一次執行會自動安裝套件，之後瀏覽器會自動開啟。

### macOS / Linux

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

瀏覽器會自動開啟 `http://127.0.0.1:8765`。加上 `--no-browser` 可以不自動開啟；用環境變數 `PORT` 可以換連接埠。

## 使用方式

1. 把 PDF 或 DOCX 拖進頁面，或點一下選擇檔案。
2. 「參考文獻列表」分頁列出每筆文獻、被引用次數、比對結果與線上驗證結果。
3. 「內文引用」分頁列出每種引用、出現次數、頁碼（PDF）、對應的文獻與上下文。
4. 勾選「只顯示有問題的」可以快速篩選。
5. 按「匯出 Excel」下載結果。

`samples` 資料夾裡有三份刻意放了錯誤的範例文件，可以先拿來試。

## 隱私

- 上傳的檔案只在本機處理，分析完就刪除暫存檔。
- 勾選「線上驗證」時，**每筆參考文獻的文字**會送到 Crossref（`api.crossref.org`）與 `doi.org` 查詢；論文內文不會送出。取消勾選就完全離線。
- Email 欄位是選填的。填了會隨查詢送給 Crossref，查詢速度較穩定；它只存在你瀏覽器的 localStorage。

## 限制

- 掃描影像的 PDF 要先做 OCR；舊版 `.doc` 要另存為 `.docx`。
- 不支援註腳式引用（例如 Chicago notes-bibliography）。
- 敘述式引用若姓氏沒有大寫（`choi (2020)`）無法辨識。
- PDF 排版差異很大（雙欄、沒有懸掛縮排等），參考文獻的切分可能出錯，請對照原文確認。
- 上標數字引用是靠 PDF 的上標格式辨識的，註腳編號或數學上標可能被誤判。
- 書籍、網頁、學位論文、中文文獻在 Crossref 常查不到，會顯示「查無資料」，不代表文獻有錯。
- 沒有 DOI 的文獻用標題搜尋時，可能配到同標題的另一個版本（例如重刊），這時只會提示年份不同。
- 這是輔助工具，標出的問題需要人工判斷；沒標出也不保證沒有錯。
